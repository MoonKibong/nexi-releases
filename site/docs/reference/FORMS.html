양식

양식

읽기 안내 — 누가: PM, FDE, Practice Lead · 언제: 착수 합의, 주기 계획, 막힌 일, 측정, 실패, 인수인계, 아키텍처 결정을 기록할 때 · 읽은 뒤: 맞는 양식을 복사해 채우고, 프로젝트에서 정한 곳(보통 해당 이슈나 docs/ 아래)에 둔다.

NEXI 키트가 만드는 파일(요구사항 결정 문서, 작업 계약서, 증거, 판정 기록, 최종 보고)의 형식은 산출물 참조에 있다. 아래는 키트가 만들지 않아 사람이 직접 남기는 기록이다. 채울 수 없는 항목은 짐작으로 채우지 말고, 누가 언제까지 정할지 적는다.

양식 쓰는 때
기회 평가 고객과 처음 만나 맡을지 정할 때(착수 합의와 견적)
범위와 성공 계약 착수 합의를 서면으로 남길 때
고객 맥락과 운영 규칙 착수 합의에서 일하는 방식을 정할 때
주기 계획 2주 주기를 시작할 때
막힌 일 기록 BLOCK, 세 번째 연속 REVISE, 보안·데이터 신호로 사람이 정해야 할 때
측정 기록 고객과 측정하기로 했을 때 작업마다(비용과 시간 기록하기)
실패 기록 실패가 있었을 때 실패마다
인수인계와 최종 평가 고객에게 넘길 때(인수인계)
아키텍처 결정 기록(ADR) 중요한 아키텍처를 고를 때(레거시 저장소에서 시작하기)
