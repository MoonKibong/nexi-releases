NEXI 키트 skill 참조

읽기 안내 — 누가: NEXI 키트로 프로젝트를 하는 사람 · 언제: skill 하나가 무엇을 하고 언제 멈추는지 알아야 할 때 · 읽은 뒤: 알맞은 프롬프트로 skill을 부르고, 멈췄으면 그 이유를 보고 다음 일을 정한다.

NEXI 키트에는 skill 열 개가 있다. 아래에서 하는 일을 고르고, 상세 페이지에서 입력과 산출물, 멈추는 경우와 다음 프롬프트를 본다. 실행할 때는 설치된 키트의 원문을 따른다. 버전 확인과 공통 조건은 공통 규칙에 있다.

한눈에 보기

skill 하는 일 누가(팀)
nexi-init 저장소와 작업 규칙을 만든다 PM
nexi-requirements 요구사항을 분석하고 결정 문서를 만들어 승인받는다 FDE, 승인은 PM
nexi-backlog 작업 이슈를 만들고 다음에 할 작업을 고른다 PM, next는 FDE
nexi-contract 작업 하나의 계약서를 쓰고 승인받는다 FDE, 승인은 PM
nexi-design 화면의 디자인 기준(BRIEF)을 쓴다 FDE
nexi-implement 계약서대로 구현하고 검사 결과를 증거로 남긴다 개발자
nexi-review 구현하지 않은 agent가 리뷰하고 판정을 기록한다 검토자
nexi-merge APPROVE된 작업을 main에 넣고 이슈를 닫는다 PM
nexi-finish 새 사본에서 전체를 검증하고 최종 보고서를 승인받는다 PM
nexi-run(선택 기능) 구현, 리뷰, 판정 기록을 한 번에 돌린다 개발자

보통 순서는 nexi-init → nexi-requirements → nexi-backlog → 작업마다 nexi-contract(화면 기준 작업은 nexi-design도) → nexi-implement → nexi-review → nexi-merge → nexi-finish다.

모든 skill에 공통인 규칙

공통 규칙에서 원문과 버전, 승인, 원격 실패와 재개를 확인한다.

nexi-init

프로젝트 시작을 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.

nexi-requirements

요구사항 결정을 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.

nexi-backlog

작업 목록과 다음 작업을 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.

nexi-contract

작업 계약서를 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.

nexi-design

화면의 디자인 기준을 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.

nexi-implement

계약서대로 구현을 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.

nexi-review

독립 리뷰와 판정 기록을 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.

nexi-merge

병합과 작업 수용을 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.

nexi-finish

전체 검증과 최종 확인을 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.

nexi-run (선택 기능)

구현과 리뷰 반복을 맡는다. 명령, 입력과 산출물, 멈추는 조건을 읽는다.
