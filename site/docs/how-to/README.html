진행 경로

상황 글 읽고 할 일
한 사람이 새 프로젝트를 맡는다 혼자 진행하기 요구사항 승인부터 독립 리뷰, 수용과 최종 확인까지 순서대로 한다.
여러 사람이 역할을 나눠 진행한다 팀으로 진행하기 각자의 차례와 원격 기록을 보고 다음 사람에게 넘긴다.
예전 시스템 옆에 새 시스템을 만든다 새 저장소로 시스템 옮기기 비교 기준과 검사부터 정하고 조각마다 옮긴다.

단계별 상세는 시작하기, 명령과 멈춤 조건은 skill 참조에 있다.
